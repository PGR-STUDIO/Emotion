# PGR Studio

PGR Studio est un studio de création d'applications et de solutions numériques. La version 0 établit une organisation claire, simple et évolutive avant tout développement produit.

## Vision

Construire plusieurs produits utiles, documentés et maintenables avec une méthode de travail progressive, assistée par ChatGPT, Codex et GitHub.

## Fonctionnement général

- `00_DIRECTION/` définit la vision, la stratégie, les objectifs et les décisions du studio.
- `01_PLATFORM/` regroupe les éléments communs réutilisables entre les produits.
- `02_PRODUCTS/` contient un espace séparé pour chaque produit.
- `03_RESEARCH_LAB/` rassemble les recherches et études nécessaires.
- `04_BUSINESS/` organise les sujets commerciaux et clients.
- `05_OPERATIONS/` centralise les opérations, la sécurité, les sauvegardes et les outils.
- `99_ARCHIVES/` conserve les éléments historiques qui ne sont plus actifs.

## Méthode de travail

```text
Idée
  ↓
ChatGPT (analyse et conception)
  ↓
Codex (développement)
  ↓
GitHub (version et sauvegarde)
  ↓
Tests
  ↓
Amélioration
```

## Règles de la version 0

- Garder une architecture simple.
- Documenter les décisions importantes.
- Ne pas inventer de fonctionnalités avant validation.
- Ne pas coder d'application dans cette fondation.
- Conserver les versions et rendre les évolutions traçables.

## Démarrage

Commencer par lire `00_DIRECTION/VISION.md`, puis compléter les documents de direction avant d'ouvrir le développement d'un produit.
